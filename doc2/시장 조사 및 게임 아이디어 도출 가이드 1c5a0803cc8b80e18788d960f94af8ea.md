# 시장 조사 및 게임 아이디어 도출 가이드

## 1. 핵심 설계 기반

| 구분 | 핵심 평가 영역 | 성공적인 게임 아이디어를 위한 주요 성과 요소 |
| --- | --- | --- |
| **MARKET** | **시장성과 트렌드** | - 장르 시장 규모는 충분히 큰가?
- 이 틈새시장이 성장하고 있는가?
- 진입하는 신규 개발사가 늘고 있는가?
- 향후 변화 가능성은 어떻게 예측되는가? |
| **AUDIENCE** | **타겟 유저에 대한 이해** | - 우리 유저는 누구인가?
- 이들이 게임에서 진짜로 원하는 가치는 무엇인가?
- 비슷한 게임에 대해 어떤 피드백을 남겼는가?
- 이 게임은 어떤 '욕망'을 해결해주는가? |
| **PITCH & EXPERIENCE** | **커뮤니케이션과 사용자 경험** | - 한 문장으로 게임을 매력적으로 설명할 수 있는가?
- 15초짜리 재미있는 영상이 머릿속에 떠오르는가?
- 20분 뒤 플레이어는 무엇을 기억하게 될까? |
| **GAME DESIGN** | **핵심 게임 설계** | - 컨셉이 충분히 독창적인가?
- 코어 루프는 단순하면서 중독적인가?(메카닉)
- 아트 스타일은 주목 받을 수 있는가?
- 반복 접속을 유도할 수 있는 재미 포인트가 존재하는가? |

## 2. 실행 점검

| 구분 | 핵심 평가 영역 | 성공적인 게임 아이디어를 위한 주요 성과 요소 |
| --- | --- | --- |
| **COMPETITION** | **경쟁 분석** | - 주요 경쟁작은 무엇이고, 무엇이 성공요인인가?
- 우리는 어떤 점에서 차별화되는가?
- 실패한 사례는 무엇이고, 원인은 무엇인가? |
| **DEVELOPMENT** | **개발 가능성과 리스크** | - 우리는 이 아이디어를 만들 기술과 인력이 있는가?
- 출시까지 얼마나 걸릴 것인가?
- 빠르게 프로토타입을 만들 수 있는가?
- 예상되는 주요 리스크는 무엇인가? |

## 3. 성장/수익 기반

| 구분 | 핵심 평가 영역 | 성공적인 게임 아이디어를 위한 주요 성과 요소 |
| --- | --- | --- |
| **MARKETING** | **마케팅 전략** | - 타겟 오디언스에게 어떻게 도달할 것인가?
- 커뮤니티를 어떻게 구축할 것인가?
- 인플루언서와의 협업 가능성은?
- 이 게임은 바이럴 될 가능성이 있는가? |
| **MONETIZATION** | **수익화 모델** | - 수익화는 어떤 방식으로 이루어지는가?
- 수익화 방식이 게임 경험을 해치지 않는가?
- 인앱구매는 어떤 구조로 설계되는가?
- 출시 이후의 수익 전략은 무엇인가? |
| **BUSINESS** | **비즈니스 관점** | - 어느 정도의 자금이 필요한가?
- 손익분기점은 어느 정도 수익인가?
- 성공을 정의할 핵심 KPI는 무엇인가? |
